# 量具全生命周期与产品检验管理系统 PRD

版本：v0.1 · 2026-11-25 · 供测量中心和品质部门确认，供 LoopForge Planner 拆单

## 1. 背景与目标

测量中心用 Excel 台账管理量具，产品检验结果也在 Excel 中记录。旧台账有 567 条记录，其中 80 条内校或外校记录标为「正常」，但下次校验日期早于 2026-11-25；另有 55 条记录的数量大于 1，需核对一个管理编号是否对应多件实物。上述统计为源表快照，用于确定迁移核对项。

首期建立一个公司内部应用，同时替代量具台账和首批上线范围内的产品检验 Excel。测量中心负责量具放行，检验员在应用内登记和提交正式检验记录。应用须在首次登记使用和正式提交时核验实际量具的资格，并支持从量具追溯使用单位、人员、检验记录和产品批次。

评估过两条路径：保留检验 Excel、增加量具核验入口，现场切换成本较低，但无法在最终检验记录提交时统一执行规则；由应用承接台账和正式检验记录，可在同一条流程中执行拦截和追溯。按用户明确的替代 Excel 目标，本 PRD 采用第二条路径。

### 1.1 首期边界

- 覆盖采购登记、验收、放行、领用归还、调拨、校验、维修、降级、停用、丢失和报废，以及按人员和使用单位授权、检验记录和异常追溯。
- 采购记录到采购单号、供应商、到货及验收；审批付款、库存财务和 ERP 集成留待后续。产品检验覆盖批次、样品、检验项目、实测值、判定及用具记录；整套 QMS、MES、SPC、电子签章、设备联网和离线放行不在首期。
- 台账及首批启用范围内的新检验记录以应用为准。Excel 用于一次性台账迁移、只读历史查阅和报表导出。历史产品检验结果暂归档，不作为首期批量导入范围。

## 2. 角色与权限

| 角色 | 权限范围 |
| --- | --- |
| 测量中心人员 | 管理量具和使用单位，登记采购、验收、领用归还、调拨、校验及维修。按岗位权限执行放行、免校批准、降级、隔离和报废，查询跨部门量具使用记录。 |
| 使用单位负责人 | 查看本单位量具、人员授权和到期项，发起领用、归还、调拨或送修申请，管理本单位人员的检验资格申请。申请不会生效为量具放行或跨单位授权。 |
| 检验员 | 查询本人获准使用的量具，创建和提交本单位检验记录。可申请更正本人已提交的记录。 |
| 品质负责人 | 管理检验项目、适用量具范围和检验模板版本。审查更正、处理异常影响批次，查看授权范围内的检验、风险和追溯记录。 |
| 系统管理员 | 管理账号、部门、角色及基础字典。业务放行、有效期修改和降级批准须具备测量中心对应权限。 |

使用单位指厂区、部门或班组等组织节点，与旧表的数量计量单位区分。量具归属单位、当前保管单位和保管人单独记录。检验员须有有效账号、当前单位成员资格、有权限执行指定检验项目，并在被授权的量具或量具类别范围内。量具授权限定使用单位、人员或岗位范围及有效期。调拨或临时跨单位使用须有明确授权。权限在服务端执行，名单、详情、报表和导出应用相同的数据范围。无有效授权时拒绝使用。

## 3. 量具生命周期

| 环节 | 必须记录或执行 |
| --- | --- |
| 采购与入账 | 采购记录含单号、供应商、购入/到货日期和数量。实物入账时分配唯一管理编号，记录仪器名称、规格、量程、分辨力或精度、产品序号（有则记）、归属单位。一个可独立使用的实物对应一个编号，编号归档后不复用。 |
| 验收与首次放行 | 验收记录含日期、人员、结论和凭证（如有）。不合格保持停用。通过验收仍须有测量中心确认的内校/外校合格记录，或已批准且适用的免校依据，才可放行。未领用量具留在库存。 |
| 领用、归还与调拨 | 每次记录交出与接收单位、保管人、时间和原因。正常归还仅回到库存，原校验证据继续按原有效期计算。出库前重新核验资格，无异常时无需因正常归还重复校验。调拨完成后旧单位权限失效，目标单位须获得有效授权；旧领用历史保留。 |
| 周期校验 | 区分内校、外校、免校。需校量具有周期、末次校验日期、到期日、结论、证据和经办人，外校可录证书编号或上传证书。工作台显示即将到期、已超期和送检待回。超期按校验日期实时判定，不依赖提醒任务是否执行。 |
| 维修、送检、丢失与停用 | 状态生效后立即停止使用。送检返回、维修完成或找回均进入待复核。需校量具依据本次合格校验记录再次放行，维修完成、找回后须复校。免校量具须重审免校依据和使用条件。 |
| 降级 | 测量中心记录原因、生效时间、旧/新精度、允许的检验项目、判定依据和批准人。降级待批准期间停止使用。批准放行后，仅允许在批准项目和规格范围内使用，且仍须符合校验或免校要求。 |
| 报废 | 测量中心确认报废，记录原因、依据、时间和人员。报废是终止状态，原编号与历史记录可查，不能重新放行、领用或用于新检验。 |

库存/领用、校验类别、最近校验结论、可用范围及当前管制状态分别记录。建议管制状态为待验收、待放行、已放行、隔离、维修中、送检中、丢失、报废；超期和正常/限用由资格计算显示。任何待处理状态不能直接视为可用。关键变更追加历史事件，保存前后状态、操作者、时间和原因。

## 4. 产品检验与拦截规则

1. 品质负责人维护检验模板，同一模板发布新版本后，已提交历史保留原版本。每个检验项目配置适用量具类别或指定量具及规格要求，并标明定量或定性。定量项目记录单位、边界和实测值，双边或单边界限均包含边界值；定性项目记录明确判定。首期每个需量具的样品项目行绑定一把实际使用的量具，同一批次允许多个样品和检验项目。
2. 检验员录入产品编码、批次、检验环节和样品，按项目输入或选取实物管理编号。使用实物前，服务端先核验候选用具，通过后登记本次使用确认和资格证据。检验员在该项目下录入实际测量结果。未通过时返回拒绝原因，可改用合规量具。业务错误至少区分未放行、已停用、校验过期或缺失、免校未获批准、单位无权、人员无权、精度或范围不匹配。
3. 使用资格是所有条件同时成立：量具已放行、已领用到当前单位或处于批准的临时跨单位使用期，当前管制状态允许，合格校验证据在有效期内或有适用的有效免校批准，人员和单位授权有效，量具及降级后的精度和范围满足该项目。免校不自动放行。未知或缺失的关键信息默认拒绝。初版按 `Asia/Shanghai` 判断校验到期日，到期日当天有效，次日 00:00 起拒绝；免校以批准的有效期和范围判断。现场与系统政策不同时，由测量中心在设计评审中确认规则。
4. 正式提交时，服务端用实际量具和最新状态重新计算资格，并检查用具确认至提交期间是否发生了导致授权、管制状态、校验证据或适用范围失效的事件。放行恢复不得使失效的旧确认重新有效。资格校验与正式记录、判定及资格快照的写入须是原子操作，覆盖并发停用。任一行不合规则保留草稿，拒绝整个提交。对重复提交应返回原结果或明确提示已提交，不能生成第二份正式记录。若旧确认失效，检验员须重新确认合规量具、实际重检并录入新的结果。替换管理编号时同样使该行旧确认和旧结果失效，保留变更历史。
5. 正式检验记录含产品、批次、检验环节、样品、项目、实测值/判定、实际量具编号、检验人员、单位、用具确认时间和提交时间。任何检测项目不合格时批次检验结果为不合格，业务追溯仍保留；量具不合规则禁止提交，两类结果分开。已提交记录用更正流程保留原件、理由、批准人和关联新版本。更正文书不得为过去未获放行的使用补造资格凭证，重检应产生新的使用记录。
6. 正式入口不接受离线放行。现场须先完成系统核验才可操作实物，系统拦截的是使用确认和正式检验提交。试点应核对量具标识与实物一致，并取消该范围用 Excel 新建正式检验记录的流程。

## 5. 不合格量具的历史影响追溯

- 量具校验不合格时，系统同次操作隔离量具，并建立一条待处理影响事件。默认风险窗口从最近一次有效合格校验时间开始，至停用生效时为止；缺少合格记录时，从首条系统用具记录开始，并显示历史覆盖不足。品质负责人可记录经核实的风险窗口调整与依据。
- 可按量具、时间、单位、人员、产品和批次查到窗口内的用具记录与正式检验结果。重复记录按检验记录关联，涉及批次可汇总。系统保留原检验判定并单列风险状态，由品质负责人记录评估、复检或处置结论。无命中也保留事件供确认。

## 6. 旧台账迁移与上线

旧 `.xls` 的表头位于第 7 行。迁移保留管理编号、部门、数量及计量单位、仪器名称、名牌号、规格、产品序号、购入和领用日期、上次/下次校验日期、校验周期、校验类别、仪器状态及备注。单位负责人和管理者保留为历史来源字段，人工映射到有效组织和人员。无法映射的人名不会创建账号或授权。

1. 支持对现有版式先预检后导入，预检不改业务数据。输出源行号、动作、冲突原因与数量汇总，至少覆盖空编号、规范化后重复编号、非法日期、无法映射的部门/人员、数量大于 1、内外校超期或校验证据缺失。保留原始编号显示和源行追溯。
2. 多件同编号记录留在待处理区，测量中心确认实物后再分配唯一编号，保留原编号与拆分关系。旧状态「正常」先作为历史源值导入；经测量中心核实有效校验证据或批准免校、领用和授权后才生效。明确报废的记录保留为报废历史，其余丢失、库存及存疑记录保持不可用。不得为缺档编造校验历史。
3. 重试同一批导入不重复建档，不覆盖已有生效的量具或有效期；冲突进入核对清单。汇总对账区分源记录数、导入/待处理/拒绝行数和拆分后的实物数量，源行需逐条可追溯。业务导入使用企业内部受控环境。开发、CI 和 LoopForge 使用保留格式的合成样本，真实台账、人员姓名、证书和产品数据不进入仓库或任务提示词。
4. 上线前用一批代表性量具和产品批次试跑，核对台账、角色、拦截和双向追溯。确认试点范围、校验日边界、免校依据、跨单位审批人、以及实际检验 Excel 样表的必填字段和判定规则；由测量中心与品质负责人共同验收。通过后将试点 Excel 置为只读并保留原始归档。

### 6.1 业务设计确认项

| 确认时点 | 业务方须确认的规则 |
| --- | --- |
| `REQ-001` 设计及迁移试跑 | 测量中心确认有效校验证据清单、缺证时的复校规则和多件同号实物拆分办法。未确认前，存量异常记录只能导入待核对区。 |
| `REQ-002` 设计 | 测量中心确认人员资格、跨单位授权和降级的审批岗位、是否允许本人审批，以及临时跨单位使用是否需要交接保管。建议默认审批人与申请人分离，仅在授权范围和时段内开放临时使用。 |
| `REQ-003` 设计 | 品质部门提供脱敏检验样表并确认抽样、复检、批次判定、最终产品放行责任、同一检验项目是否使用多把量具，以及跨班、跨日和事后录入的真实场景。第 4 节的单用具绑定、任一检测项目不合格则批次检验不合格、提交前失效须重检，均为首期设计提案。确认有不同现场规则时，先以明确场景更新 PRD，再实施对应逻辑。 |

这些确认项用于对应业务单的设计评审，`REQ-000` 可先规划和初始化骨架。

## 7. 工作台与基本运行要求

- 测量中心工作台可筛选待验收、待放行、即将到期、超期、送检、维修、隔离和迁移异常。临期提示默认提前 30 天，可配置；通知渠道和外部系统集成后置。
- 提供量具档案、组织与人员授权、校验/维修业务记录、检验录入、批次与量具追溯、台账导入预检和按权限导出。可从任一实物管理编号进入历史，从正式检验记录反查对应放行与校验凭证。
- 重要写操作均需认证及授权，写入可审计事件。业务导出受角色和数据范围控制，业务备份与恢复需演练。测试和日志使用脱敏或合成数据。

## 8. 可测试验收标准

| 编号 | 场景与通过条件 |
| --- | --- |
| AC-1 | 新建采购关联的两件实物需有两个唯一管理编号，重复编号被拒绝。验收不合格或首次校验未确认时，无法放行或提交使用。 |
| AC-2 | 给定到期日为 D，已放行的合格内外校量具在上海时间 D 23:59 可正常确认使用，D+1 00:00 被拒绝。没有有效免校批准时，即使类别为免校也被拒绝。 |
| AC-3 | 合法单位与人员可使用已分配量具。无权人员、他单位、账号停用、资格过期或转出原单位分别被服务端拒绝，列表和导出不泄露其他单位数据。 |
| AC-4 | 登记归还、送检、维修、丢失或隔离后，下一次使用确认立即失败。无异常的正常归还保留原校验证据，并可在凭证有效且重新领用后使用。完成维修仍不可放行，合格校验或符合条件的免校复核后可由测量中心放行。报废无法恢复成可用。 |
| AC-5 | 同一把降级量具在批准的项目和量程内可通过，在原精度要求、未批准项目或范围外被拒绝。历史检验仍保留当时用具快照。 |
| AC-6 | 合规检验记录提交后能按批次和量具双向查到实际用具和资格证据。若任一量具在确认后、提交前被停用或授权撤销，整个提交被拒绝并保留草稿。重新放行不能复用失效确认。更换量具需重新确认并录入实测值，重复提交不新增正式记录。 |
| AC-7 | 定量值恰好等于版本化模板的限值可判合格，越界则判不合格。合法用具测出的不合格结果可提交留档，量具资格不合规的记录不可提交。更正关联原件并保留审批与审计事件。 |
| AC-8 | 某量具录入校验不合格后立即隔离。系统列出风险窗口内使用过该量具的检验记录及批次，窗口外记录不进入本次影响清单。品质处置保留原检验结果和处理证据。 |
| AC-9 | 用合成 `.xls` 试导入重复编号、超期但标为正常、免校缺批准、报废、无法映射人员和数量大于 1 样例。预检无业务写入，导入结果逐行可追溯，异常不自动放行，重复导入不重复建档。 |
| AC-10 | 未授权角色不能通过界面或接口放行、改有效期、批准降级、跨单位访问或导出。经授权的状态变更保留操作者、时间和原因，普通用户不能覆写已提交记录或删除审计事件。 |

## 9. LoopForge 交付顺序

当前仓库 `bootstrapped: false`，业务构建和测试命令尚未配置。先由 Planner 对 `REQ-000` 产出初始化设计，经人工确认后，按仓库 README 在授权维护环节搭建骨架和启用门禁。正式 SOP 的 Developer 和 Reviewer 角色遵守仓库保护路径。基座验收完成后，再让 Planner 为后续每单给出模块与路径白名单、数据/API 契约、前置依赖和验收证据。

| 建议需求单 | 级别 | 实现顺序与验收归属 |
| --- | --- | --- |
